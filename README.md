# Framer Components — Corsica Studio

Collection de composants Framer production-ready, conçus pour des sites web modernes et performants.

## Composants disponibles

### AnimatedButton
Bouton avec animations spring au hover et au clic. Entièrement personnalisable via les property controls Framer.

**Props :** label, backgroundColor, textColor, borderRadius, fontSize, paddingX, paddingY, hoverScale

---

### ScrollReveal
Apparition au scroll avec détection `useInView`. Supporte 5 directions : haut, bas, gauche, droite, fondu.

**Props :** direction, distance, duration, delay, once

---

### MarqueeText
Texte défilant en boucle (logos, services, mots-clés). Pause au survol optionnelle, direction configurable.

**Props :** items (array), separator, speed, direction, fontSize, textColor, backgroundColor, gap, pauseOnHover

---

### GradientCard
Carte avec gradient animé, effet hover élévation, overlay texture, tag coloré.

**Props :** title, description, tag, gradientFrom, gradientTo, gradientAngle, textColor, tagColor, borderRadius, padding, animateOnHover

---

## Installation dans Framer

1. Ouvrir le projet Framer
2. Aller dans **Assets > Code**
3. Créer un nouveau composant
4. Copier-coller le contenu du fichier `.tsx` souhaité
5. Le composant apparaît dans la liste avec tous ses controls
